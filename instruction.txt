Rôle des agents :

1. OrchestratorAgent
Fichier : agents/orchestrator_agent.py
Responsabilité :
- recevoir un dataframe brut ;
- appeler tous les agents dans le bon ordre ;
- retourner un dictionnaire final avec :
  - raw_shape
  - cleaned_dataframe
  - cleaning_stats
  - quality_report
  - kpis
  - insights
  - recommendations
  - markdown_report

2. DataCleaningAgent
Fichier : agents/data_cleaning_agent.py
Responsabilité :
- supprimer les lignes complètement vides ;
- supprimer les lignes où la colonne “Order ID” contient “Order ID” ;
- convertir “Quantity Ordered” en numérique ;
- convertir “Price Each” en numérique ;
- convertir “Order Date” en datetime ;
- supprimer les lignes invalides après conversion ;
- créer une colonne “Sales” = Quantity Ordered * Price Each ;
- extraire la ville et l’état depuis “Purchase Address” dans une colonne “City” au format “City (State)” ;
- créer les colonnes “Hour”, “Day” et “Month” ;
- retourner le dataframe nettoyé et des statistiques de nettoyage.

3. DataQualityAgent
Fichier : agents/data_quality_agent.py
Responsabilité :
- compter les lignes brutes ;
- compter les lignes après nettoyage ;
- compter les lignes vides supprimées ;
- compter les en-têtes répétés supprimés ;
- compter les doublons ;
- détecter les valeurs manquantes ;
- calculer un score qualité sur 100 ;
- expliquer les problèmes détectés clairement.

4. KPIAgent
Fichier : agents/kpi_agent.py
Responsabilité :
- calculer le chiffre d’affaires total ;
- calculer le nombre de commandes uniques ;
- calculer le nombre total d’unités vendues ;
- calculer le panier moyen ;
- calculer le prix moyen par ligne ;
- trouver le produit qui génère le plus de chiffre d’affaires ;
- trouver le produit le plus vendu en quantité ;
- trouver la ville qui génère le plus de chiffre d’affaires ;
- trouver la meilleure heure de vente ;
- trouver le meilleur jour de vente.

5. ChartAgent
Fichier : agents/chart_agent.py
Responsabilité :
- générer les données nécessaires aux graphiques ;
- ne pas faire de calculs métier dans Streamlit ;
- préparer :
  - top 10 produits par chiffre d’affaires ;
  - top 10 produits par quantité vendue ;
  - chiffre d’affaires par ville ;
  - chiffre d’affaires par heure ;
  - chiffre d’affaires par jour ;
  - distribution des ventes.

6. BusinessInsightAgent
Fichier : agents/business_insight_agent.py
Responsabilité :
- transformer les KPI en analyse business ;
- produire un résumé exécutif ;
- expliquer les tendances principales ;
- expliquer les produits, villes et horaires les plus importants ;
- ne jamais inventer de données.

7. RecommendationAgent
Fichier : agents/recommendation_agent.py
Responsabilité :
- proposer des recommandations marketing ;
- proposer des recommandations produits ;
- proposer des recommandations horaires ;
- proposer des recommandations data quality ;
- chaque recommandation doit être liée à un KPI réel.

8. ReportAgent
Fichier : agents/report_agent.py
Responsabilité :
- générer un rapport Markdown complet ;
- inclure :
  - titre ;
  - résumé exécutif ;
  - qualité des données ;
  - KPI ;
  - insights ;
  - recommandations ;
  - limites du dataset.

9. QAAgent
Fichier : agents/qa_agent.py
Responsabilité :
- répondre aux questions utilisateur dans Streamlit ;
- utiliser uniquement les KPI, quality_report, insights et recommendations ;
- répondre aux questions sur :
  - KPI ;
  - meilleur produit ;
  - meilleure ville ;
  - meilleure heure ;
  - qualité des données ;
  - recommandations ;
  - résumé global ;
- si la question est hors périmètre, répondre clairement :
  “Je peux répondre uniquement aux questions liées aux ventes, KPI, produits, villes, horaires, qualité des données et recommandations.”
